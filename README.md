# QR Code Generator

A robust tool for generating customized QR codes.

## Features
- **CLI**: Advanced command-line interface for automation.
- **GUI**: User-friendly Streamlit web interface.
- **Customization**: Error correction, box size, border, fill/background colors.

## Installation
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

### Command Line
```bash
python src/main.py "https://example.com" -o output.png
```

### GUI (Web App)
```bash
streamlit run src/app.py
```

### Standalone Executable
Click this link: https://qr-code-generator-jay.streamlit.app/
